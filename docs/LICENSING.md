# Source and release licensing

This private working repository has not selected a blanket code or dataset license. Select those explicitly before an open release.

Every source retains its own terms. An article's open license does not automatically cover externally referenced databases, third-party figures, supplementary files or model outputs produced under another provider's terms.

- `attribution_required`: an open license was observed for the main article. Still audit exact material and attribution at extraction/release.
- `needs_review`: rights or primary access are unresolved. Not eligible for the initial training release.
- `reference_only`: keep the bibliographic pointer; do not include copied content in the initial commercially reusable corpus without further clearance.

The Yoo article states CC BY-NC 3.0. The Rawlings–Ekerdt author site provides free reading with a copyright notice; an open reuse license was not verified. Aali–Hadi's CC BY status is reported by CHEPTA but has not been rechecked in its primary PDF here.

The other four priority papers have observed CC BY 4.0 main-article licenses. Attribution and source-specific review remain required. Training on a paper and redistributing a paper are separate uses; this repository currently does neither.

Keep the eventual base model license and any synthetic-data provider terms in the model release record. Do not represent generated explanations as text authored by the cited researchers.
