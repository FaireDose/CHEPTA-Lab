## Noted, not requested (a nearby setting works, or the answer is consistent)

- **Version:** `node bin/chepta.mjs --version` on 415da41 prints `0.6.2`; every run manifest records the commit sha so a
  run can be told from 0.6.2 by that only. For CHEPTA's release step, not a capability.
- **Column 11 on its bottoms purity** (u62-scds11-acid-purity): still the 31 kmol/h root (2,731 kg/h of 99.90 % ester);
  the distillate or bottoms flow works nearby (99.85-99.92 % at 140-141.5 kmol/h of product), so practice step 8
  applies, not a request.
- **Column 11's distillate in the cold-start loop** (plant62-R-dist255/260-*-tol3e-4: `NO_CONVERGENCE`; -RD4:
  `OUT_OF_TIME`): from the settled start the loop converges at 246 and 270 kmol/h, so the start, not the column, is
  the limit. At 260 kmol/h from the cold start the reactor runs short of ethanol (practice step 7).
- **Runs that stopped fast on 0.6.2 and now run to their time limit** (plant62-W-dist and its variants, plant62-R-*-direct):
  the column fixes let the loop go on; it then plateaus near 4.6e-4 (Broyden). Not a regression; recorded per run.
